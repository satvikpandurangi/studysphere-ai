# Historical construction scripts

`legacy-scripts/` preserves 23 Python scripts from the September build. They contain exact text replacements and old `outputs/studysphere-ai/` paths. Several remove or rewrite code sections. They are historical evidence, not supported setup/maintenance commands.

Use the maintained tools in [scripts](../scripts/README.md). Local browser profiles, installed Python packages and caches were retained under ignored `.local/legacy-runtime/`; old release packages are under ignored `artifacts/archive/`.
